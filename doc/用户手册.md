# 媒体文件整理工具 — 用户手册 v1.5

---

## 一、这是什么工具

**一句话：帮你把散落在各处的照片、视频、音频，按条件筛选后，一键复制到多个备份盘。**

你不需要在 Everything 里搜索文件、再手动打开资源管理器复制、再粘贴到另一个窗口 —— 一个工具全搞定。

> 适用系统：Windows 7/10/11（64 位）

## 四、快速上手（5 分钟）

### 步骤 1：添加源目录

> **[此处截图：软件主界面，红色箭头指向源目录区域]**

点击 **＋ 添加** 选择文件夹，或点 **🖥 检测设备** 自动发现所有硬盘和 U 盘。

勾选你要扫描的目录。系统盘默认不勾选（安全考虑）。

### 步骤 2：扫描文件

> **[此处截图：扫描中，进度条和文件计数实时增长]**

点击 **🔍 扫描**。工具会遍历所有勾选的源目录，找到图片、视频和音频文件。

扫描过程中：
- 进度条实时更新
- 文件数量持续增长
- 随时可点 **取消** 中止

### 步骤 3：查看和筛选

> **[此处截图：文件列表，标注 checkbox 列、筛选下拉框、全选按钮]**

扫描完成后，你可以：

| 操作 | 方法 |
|------|------|
| 勾选文件 | 点击每一行左边的 ☑ |
| 全选/取消 | 点击 **全选** 按钮 |
| 按类型筛选 | 下拉框选择"仅视频"/"仅图片"/"仅音频" |
| 排序 | 点击列头（文件路径、大小、分辨率、时长、编码） |
| 查看位置 | 双击任意行 → 资源管理器打开 |
| 复制路径 | 右键 → 复制完整路径 |

元数据（分辨率、时长、编码）会在扫描后**自动提取**，提取过程中可正常操作表格。

> **[此处截图：元数据提取完成后的表格，展示分辨率列、时长列、编码列]**

### 步骤 4：选择目标

> **[此处截图：目标位置区域，绿色高亮]**

点击 **＋ 添加** 选择目标文件夹，或点 **🖥 检测磁盘** 自动发现可用的备份盘。

你可以同时添加**多个目标**。文件会同时复制到所有目标位置。

每个目标旁边标注了磁盘类型和复制策略：
- `[HDD 机械盘]` → 串行复制（避免磁头争抢）
- `[SSD 固态盘]` → 2 线程并行
- `[NVMe 高速盘]` → 3 线程并行

### 步骤 5：开始复制

> **[此处截图：复制中，进度条和状态文字]**

勾选要复制的文件后，点击 **▶ 开始复制**。

如果你只勾选了部分文件，工具会弹框确认，你可以选择：
- **导出清单** → 先导出勾选文件的列表核对
- **确认复制** → 直接开始
- **取消复制** → 回去重新勾选

复制过程中：
- 每个目标显示独立进度
- 大文件支持中途取消（CopyFileEx 回调机制）
- 复制失败会显示具体错误原因

> **[此处截图：复制完成的日志，显示成功/失败统计]**

### 复制选项说明

| 选项 | 作用 | 建议 |
|------|------|------|
| ☑ 跳过已存在的文件 | 目标中已有同名+同大小的文件则跳过 | 重复备份时开启 |
| ☑ 保留原始时间戳 | 复制后文件保持原始拍摄/创建时间 | 默认开启 |

## 五、功能详解

### 5.1 批量选择文件

| 功能 | 操作 |
|------|------|
| 勾选单个 | 点击行首 ☑ |
| 全选 | 点击 **全选** 按钮（再点一次取消全选） |
| 快速定位 | 选中表格任意行，左下角显示"第 N 条" |
| 右键菜单 | 打开文件位置 / 复制完整路径 / 复制文件名 |
| Delete 键 | 在源目录或目标目录列表中删除选中项 |

### 5.2 导出文件清单

点击右上角 **📋 导出清单**，支持两种格式：
- **TXT**：适合打印和阅读
- **CSV**：适合用 Excel 打开、做进一步分析

### 5.3 配置自动保存

关闭工具时会自动保存：
- 源目录列表和勾选状态
- 目标目录列表
- 文件类型过滤器
- 复制选项（跳过已存在、保留时间戳）
- 窗口大小和位置

下次启动自动恢复。

### 5.4 磁盘空间不足保护

复制开始前，工具会比较待复制文件的总大小和每个目标磁盘的可用空间。如果空间不足，会弹出详细警告：

```
目标磁盘空间不足！
总计需要: 45.6 GB
空间不足的目标:
  E:\Backup (需要 45.6 GB, 可用 12.3 GB)
是否仍要继续复制？
```

### 5.5 筛选栏（⚙ 筛选）

点击 **⚙ 筛选** 可展开文件类型过滤器，修改要扫描的扩展名。格式：空格分隔，如 `*.mp4 *.jpg *.png`。修改后下次扫描生效。

## 六、典型工作流

### 工作流 1：拍摄后归档

```
1. 插上 SD 卡和备份硬盘
2. 点 🖥 检测设备 → 自动添加 D: (SD卡) 和 E: (备份盘)
3. 点 🔍 扫描 → 看到所有照片和视频
4. 点 全选 → 点 ▶ 开始复制 → 完成
   （如果你有 2 个备份盘，添加两个目标，一次复制到两个位置）
```

### 工作流 2：查找所有 4K 视频

```
1. 添加源目录（可以是多个盘）
2. 点 🔍 扫描 → 等待元数据提取完成
3. 下拉框选"仅视频"
4. 点击"分辨率"列头排序 → 所有 4K 视频排在最前面
5. 勾选这些文件 → 点 ▶ 开始复制
```

### 工作流 3：清理重复文件

```
1. 扫描所有源目录
2. 勾选"跳过已存在的文件"
3. 全选 → 复制到备份盘
4. 工具自动跳过已备份的文件，只复制新增的
```

## 八、FAQ

**Q: 支持哪些文件格式？**
A: 默认支持常见视频（MP4/AVI/MKV/MOV/WMV/FLV/WebM）、图片（JPG/PNG/GIF/BMP/TIFF/WebP/HEIC）、音频（MP3/WAV/FLAC/AAC/OGG）。可在 ⚙ 筛选 中自定义。

**Q: 元数据提取为什么有时候慢？**
A: 视频文件的元数据提取取决于文件大小和编码复杂度。工具使用 ParseSpeed=0（仅读文件头），绝大多数文件在几十毫秒内完成。如果遇到无法解析的文件，日志会打印文件名，自动跳过不阻塞。

**Q: 可以只复制勾选的文件吗？**
A: 是的。勾选后点击复制，工具只复制已勾选的文件。如果忘记勾选，会弹框提示。

**Q: 复制到一半出错了怎么办？**
A: 工具会显示具体错误（如"磁盘已满"、"访问被拒绝"），并在日志中列出所有失败的文件。已成功复制的文件不受影响。你可以修正问题后，勾选"跳过已存在文件"重新复制——只会补上之前失败的文件。

**Q: 要不要安装？**
A: 不需要。把 `untitled.exe` 和 `MediaInfo.dll` 放在同一目录即可运行。

**Q: 为什么没有"移动"（剪切）功能？**
A: 移动是不可逆操作。一旦出错，源文件已被删除，无法恢复。本工具只做复制，源文件始终安全。复制完成后，你可以手动删除源文件。
